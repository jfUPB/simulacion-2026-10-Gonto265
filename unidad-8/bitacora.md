### Actividad 2

Usaré Flow Fields, este en p5.js funcionaba dividiendo el anvas en una grilla para asignar un grado o dirección a cada división y después permitir que unos agentes sean afectados por dicha dirección y asi desplazarse por el canvas.

Quisiera transferirlo ya que adaptar esto a un espaci 3D me parece interesante además de que daría una posibilidad muy grande de estilo para objetos Tridimensionales.

Me imagino usando un mapa de Flow Fields sobre un mesh 3D para darle un recubrimiento interasnte y generativo.

Anticipo dificultad con la transferencia del campo de movimiento de los agentes exactamente sobre la capa del objeto 3D.

### actividad 3

Necesito aprender Noise Texture, Math, Simulation, Color Ramp, Vector, Curve to Mesh, Set Position, Set Curve, Join Geometry, Distribute Points on Faces, Attributes, entre otras.

Después de intentar realizar un movimiento de tipo Flow Fields con los puntos del nodo Distribute Points to Faces, Realmente hay un movimiento pero falta poner rastro y que lo que se ves sean lineas.

### Actividad 4

Acá el movimiento de los agentes es manejado a partir del metodo Set Position y el uso de Vectores, en p5.js es igual usando vectores que se ubican en variables que hacen parámetro para la posición de un agente.

Existen nodos para la realización de de diferentes operaciones matemáticas, como cuando en p5.js aplicabamos lógica matemática.

Los elementos de malla y elementos de curva o trazo se pueden conectar directamente.
